# 📄 VerdeVoto OCR - Extracción Inteligente de Facturas

Sistema web automatizado para la digitalización y extracción de datos de facturas y recibos utilizando **Tesseract OCR** y modelos **Google Gemini Flash**.

🌐 **Sitio Web en Vivo (GitHub Pages):** [https://viralpro.github.io/damiania/](https://viralpro.github.io/damiania/)

---

## 🚀 Características

- **OCR en el Navegador**: Reconocimiento de texto óptico procesado localmente con Tesseract.js.
- **IA de Extracción Multimodal**: Conexión directa con Google Gemini (`gemini-3.5-flash-lite`, `gemini-3.8-flash`) para estructurar datos (proveedor, número de factura, montos, ítems).
- **Historial Interactivo**: Registro de facturas procesadas con búsqueda, paginación y detalle de productos.
- **Soporte Multiformato**: Acepta archivos PDF, JPG, PNG, WEBP y HEIC.
- **Modo Híbrido**: Funciona tanto en entornos estáticos (GitHub Pages con persistencia en `localStorage`) como en servidores locales con PHP/MySQL.

---

## 🛠️ Tecnologías

- **HTML5 & CSS3 Moderno** (Tailwind CSS, Glassmorphism, Responsive UI)
- **JavaScript ES6+**
- **Tesseract.js & PDF.js**
- **Google Gemini API**
